# 🎬 IMDb Top 1000 Movies Visualization Using Matplotlib

This project explores and visualizes the **IMDb Top 1000 Movies** dataset using only **Matplotlib** for data visualization. It demonstrates how to apply fundamental plotting techniques to gain insights into ratings, genres, earnings, and movie popularity.

---

## 📁 Dataset

- **Source**: [IMDb Top 1000 Movies Dataset on kaggle]
- **File Used**: `IMDb Top 1000 Movies.csv`

---

## 🧰 Technologies Used

- Python
- Google Colab / Jupyter Notebook
- **Matplotlib** (for all visualizations)
- **Pandas** (for data handling)

---

## 📊 Visualizations Created

### 1. **Bar Chart**
- Top 10 movies by IMDb rating

### 2. **Histogram**
- Distribution of IMDb ratings

### 3. **Pie Chart**
- Proportion of top 5 genres

### 4. **Scatter Plot**
- Relationship between IMDb rating and gross earnings

## 🚀 How to Run

1. Upload the dataset (`IMDb Top 1000 Movies.csv`) to your working directory or Google Colab.
2. Open the notebook: `imdb_visualization.ipynb`
3. Run the cells in order to load the dataset and generate plots.

---

## 📌 Key Insights

- Distribution of high-rated movies is skewed toward 7–8 range.
- Certain genres like Drama and Action dominate the top 1000 list.
- Gross earnings vary significantly and are not always tied to rating.
